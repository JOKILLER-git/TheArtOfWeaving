# 制作管线：逐梭提经

## 场景与运行时

FirstWeave 组合 Loom 和 HUD。Loom 保留原有木质横梁、轨道、完成标记与动画；新增 WeaveSurface 运行时读取 Warps 实例的横坐标，排序后创建编号提经按钮。旧 Warps、Thread 在主玩法运行时隐藏，旧拖线逻辑不会触发过关。编辑器仍保留旧静态预览，精确提经和织纹效果请 F5 查看。

HUD 场景包含章节提示、目标织纹、当前状态、确认、撤销、重新开始和下一关。运行时只更新文字、可用性与显隐。玩家操作按钮允许鼠标、触摸及 Godot 默认键盘焦点导航。

## 数据与状态

WeaveLesson.target_rows 是 PackedStringArray，每个字符串表示一梭，从左到右每根经线用 1（经在上）或 0（经在下）表示。每关最多四行；next_lesson 链接下一资源，末关留空。只在已记录行与目标完整一致时发出 lesson_completed 并开放下一关。

提经选择与已织数据分开。确认会快照本梭选择，动画完成后再将该字符串加入已织数组。后续提经不会修改已有行。撤销移除最后一行并恢复该行组合；重试杀掉动画，清空行和选择。错误织满时不会继续插入，可连续撤销或重试。数据只保存在当前运行会话中。

## 绘制顺序

1. 放下经线，以及抬起经线留在底面的阴影。
2. 已织纬线，每行按已保存的 0/1 补画在上的经线短段。
3. 新纬线和梭子。
4. 抬起经线的弯曲中段，遮住梭子和新纬线。
5. 打纬时移动的筘示意线。

抬起区上端固定在横梁，下端固定在成布区边缘。中段弯曲偏移、阴影距离、亮度与短动画共同表达高度。成布区经线恢复笔直，保留逐行交错关系。此为 2D 示意，不是布料物理模拟。

## 美术与布局限制

线条使用 WeaveSurface 的导出颜色及程序化高光；横梁、背景、完成标记沿用现有资源。按钮主题复用 resources/ui/weave_theme.tres。当前标准布局使用 10 根经线、4 行织纹；复制经线时也必须修改目标宽度，并保证轨道范围和按钮间距。画布 1280×800 等比缩放，不自动重排。

当前纬线逐梭均由左到右穿过，没有连续回梭边缘连接、绳索物理、音效或存档。后续扩展更多行时需同时修改布局与资源校验。
