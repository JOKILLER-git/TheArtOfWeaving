## 脚本诊断限制

script_patch / write_text 成功写入带 class_name 的脚本，但即时诊断报告 `GDScript reload failed with error code 43`，且仅有 fallback 行号。相同脚本通过独立 Godot 语法检查、19 项回归检查以及编辑器启动的实际游戏验证；不带 class_name 的测试脚本写入时诊断为空。

因此本次将其记录为即时诊断不可靠的情况，不能据此认定代码损坏，也不能把成功写入视为验证通过。原因可能涉及校验时的全局类注册，尚未修改或修复插件内部实现。验证以新游戏进程、独立测试和运行日志交叉确认。
